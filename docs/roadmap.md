# Lenflix Roadmap

## Phase 0: decisions and foundation

Confirm metadata and video providers, territories, rights workflow, identity policy, monetization scope, and compliance requirements. Establish PostgreSQL schema, migrations, provider interfaces, observability, security headers, and environment separation.

## Phase 1: real catalogue

Implement movie, person, genre, collection, media asset, provider, rights, and ingestion entities. Synchronize a small verified catalogue, generate responsive artwork, index search, publish canonical movie pages, and ship sitemap and robots generation.

## Phase 2: viewer memory and playback

Implement accounts, watchlist, progress, history, rights-gated playback sessions, captions, player telemetry, error recovery, and honest unavailable states. Complete authorization and playback-session tests before enabling production playback.

## Phase 3: operations

Deliver admin catalogue management, rights review, submissions, collections, featured content, search reconciliation, audit logs, dashboards, and rights expiry alerts.

## Phase 4: creator and community

Add creator portal, upload quarantine, media processing, creator analytics, reviews, moderation, abuse reports, and notifications.

## Phase 5: advanced discovery

Add semantic search, natural-language recommendations, collaborative models, partner reporting, subscriptions, and creator revenue reporting only after privacy, contractual, and operational review.
